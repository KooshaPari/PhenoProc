# ADR-002: Failure Detection Strategy

## Status: Accepted

**Date:** 2026-04-05  
**Author:** Phenotype Engineering Team  
**Project:** circuit

---

## Context

We need to define what constitutes a "failure" for the circuit breaker and how failures are counted.

---

## Decision

We will use **consecutive failure counting with configurable threshold**:

```
┌────────────────────────────────────────────────────────────────┐
│              Failure Detection                                  │
│                                                                 │
│  Failure Counting:                                            │
│  - Increment on any error from wrapped function                │
│  - Reset to 0 on any success                                   │
│  - Open circuit when count >= FailureThreshold                 │
│                                                                 │
│  Success in Half-Open:                                          │
│  - Increment success count                                      │
│  - Close circuit when success >= SuccessThreshold            │
│                                                                 │
└────────────────────────────────────────────────────────────────┘
```

### Implementation

```go
type Config struct {
    FailureThreshold int           // Trip after N failures
    SuccessThreshold int         // Close after N successes in half-open
    Timeout          time.Duration // Open -> Half-Open timeout
}
```

---

## Consequences

### Positive

- **Simple**: Easy to understand
- **Predictable**: Clear threshold behavior

### Negative

- **No time window**: Old failures count forever until success
- **No percentage**: Bursts vs sustained failures treated same
