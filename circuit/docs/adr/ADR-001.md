# ADR-001: Circuit Breaker State Machine

## Status: Accepted

**Date:** 2026-04-05  
**Author:** Phenotype Engineering Team 
**Project:** circuit

---

## Context

The circuit breaker must implement a state machine to track service health and decide when to allow or reject requests.

### Requirements

1. **Three States**: Closed (normal), Open (failing), Half-Open (testing)
2. **Automatic Recovery**: Transition from Open to Half-Open after timeout
3. **Thread Safety**: Safe for concurrent use

---

## Decision

We will use **mutex-protected state machine with explicit state transitions**:

```
┌────────────────────────────────────────────────────────────────┐
│              State Machine                                      │
│                                                                 │
│  ┌─────────┐      failures >= threshold      ┌─────────┐       │
│  │  CLOSED │────────────────────────────────▶│  OPEN   │       │
│  │         │                                  │         │       │
│  │  normal │◀────────────────────────────────│ failing │       │
│  │  ops    │      timeout expires            │  fast   │       │
│  └────┬────┘                                  └────┬────┘       │
│       │                    success >= threshold    │             │
│       │              ┌─────────────────────────────┘             │
│       │              │                                           │
│       │              ▼                                           │
│       │         ┌─────────┐                                      │
│       │         │HALF-OPEN│                                      │
│       │         │ testing │                                      │
│       │         └────┬────┘                                      │
│       │              │                                           │
│       └──────────────┘                                           │
│         success                                                    │
│                                                                 │
└────────────────────────────────────────────────────────────────┘
```

### Implementation

```go
type State int

const (
    StateClosed State = iota
    StateOpen
    StateHalfOpen
)

type Breaker struct {
    state   State
    fails   int
    success int
    mu      sync.Mutex
    lastFailTime time.Time
    config  Config
}
```

---

## Consequences

### Positive

- **Clear semantics**: Well-understood pattern
- **Automatic recovery**: No manual intervention
- **Thread-safe**: Mutex protection

### Negative

- **Lock contention**: Mutex per breaker
- **Fixed thresholds**: Not adaptive
