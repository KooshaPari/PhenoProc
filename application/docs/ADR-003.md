# ADR-003: Port and Adapter Pattern

## Status
Accepted

## Context
External dependencies need:
1. Abstraction from domain logic
2. Testability through mocking
3. Swappable implementations
4. Clean boundaries

## Decision
Implement Port and Adapter pattern:
1. Define ports as Go interfaces in domain layer
2. Implement adapters in infrastructure layer
3. Dependency injection through constructors
4. Interface segregation (small, focused interfaces)

## Example

```go
// Port (domain layer)
type FeatureRepositoryPort interface {
    FindByID(ctx context.Context, id string) (*Feature, error)
    Save(ctx context.Context, feature Feature) error
}

// Adapter (infrastructure layer)
type PostgresFeatureRepository struct {
    db *sql.DB
}

func (r *PostgresFeatureRepository) FindByID(ctx context.Context, id string) (*Feature, error) {
    // PostgreSQL-specific implementation
}
```
