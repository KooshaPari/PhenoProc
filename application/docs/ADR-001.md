# ADR-001: Clean Architecture + DDD + CQRS

## Status
Accepted

## Context
The application framework must support:
1. Complex business logic
2. Testable code structure
3. Clear separation of concerns
4. Scalable architecture patterns

## Decision
Adopt Clean Architecture with DDD and CQRS:
1. Layered architecture with dependency inversion
2. Domain-driven tactical patterns (aggregates, entities, value objects)
3. Command and query separation
4. Interface-based dependency injection

## Architecture Layers

```
┌─────────────────────────────────┐
│  Interface Layer (Controllers)  │
├─────────────────────────────────┤
│  Application Layer (Use Cases)  │
├─────────────────────────────────┤
│    Domain Layer (Entities)       │
├─────────────────────────────────┤
│ Infrastructure Layer (Repos)     │
└─────────────────────────────────┘
```
