# ADR-002: Generic Use Case Framework

## Status
Accepted

## Context
Applications require consistent patterns for:
1. Command handling
2. Query processing
3. Input/output typing
4. Cross-cutting concerns

## Decision
Implement generic use case interfaces:
1. UseCase[I, O] for general operations
2. CommandUseCase[C, R] for writes
3. QueryUseCase[Q, R] for reads
4. Handler wrappers for cross-cutting logic

## Implementation

```go
type UseCase[I, O any] interface {
    Execute(ctx context.Context, input I) (O, error)
}

type CommandUseCase[C, R any] interface {
    Execute(ctx context.Context, command C) (R, error)
}

type QueryUseCase[Q, R any] interface {
    Execute(ctx context.Context, query Q) (R, error)
}
```
