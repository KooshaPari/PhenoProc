# ADR-003: Preflight Handling

## Status: Accepted

**Date:** 2026-04-05  
**Author:** Phenotype Engineering Team  
**Project:** cors

---

## Context

CORS preflight requests (OPTIONS) need special handling to inform browsers what requests are allowed.

---

## Decision

We will **handle preflight in middleware with early return**:

```
┌────────────────────────────────────────────────────────────────┐
│              Preflight Handling                                 │
│                                                                 │
│  Middleware Logic:                                             │
│  1. Check if request method is OPTIONS                         │
│  2. If yes, set CORS headers and return 204 No Content         │
│  3. If no, set CORS headers and continue to next handler    │
│                                                                 │
│  Separate PreflightHandler available for manual mounting      │
│                                                                 │
└────────────────────────────────────────────────────────────────┘
```

---

## Consequences

### Positive

- **Automatic**: No manual preflight handling needed
- **Flexible**: Can use separate handler if needed
