# ADR-002: Origin Validation

## Status: Accepted

**Date:** 2026-04-05  
**Author:** Phenotype Engineering Team  
**Project:** cors

---

## Context

We need to validate the Origin header against allowed origins to prevent unauthorized cross-origin requests.

---

## Decision

We will use **exact match or wildcard "*"** for origin validation:

```
┌────────────────────────────────────────────────────────────────┐
│              Origin Validation                                  │
│                                                                 │
│  Validation Logic:                                             │
│  1. If no origins configured, allow all (development)         │
│  2. If "*" in list, allow all origins                         │
│  3. Otherwise, exact match required                            │
│                                                                 │
│  Security Note:                                                │
│  - Never use "*" with AllowCredentials: true                  │
│  - Always validate against explicit list in production        │
│                                                                 │
└────────────────────────────────────────────────────────────────┘
```

---

## Consequences

### Positive

- **Simple**: Easy to understand
- **Fast**: O(n) string comparison

### Negative

- **No subdomain matching**: Exact match only
