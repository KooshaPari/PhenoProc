# ADR-001: CORS Header Strategy

## Status: Accepted

**Date:** 2026-04-05  
**Author:** Phenotype Engineering Team  
**Project:** cors

---

## Context

The CORS middleware must set appropriate headers for cross-origin requests. We need to decide which headers to include and how to configure them.

---

## Decision

We will use **configurable headers with secure defaults**:

```
┌────────────────────────────────────────────────────────────────┐
│              CORS Headers                                       │
│                                                                 │
│  Required:                                                     │
│  - Access-Control-Allow-Origin (configurable)                 │
│  - Access-Control-Allow-Methods (configurable)                │
│  - Access-Control-Allow-Headers (configurable)                │
│                                                                 │
│  Optional:                                                     │
│  - Access-Control-Allow-Credentials (configurable)            │
│  - Access-Control-Expose-Headers (configurable)               │
│  - Access-Control-Max-Age (configurable)                      │
│                                                                 │
└────────────────────────────────────────────────────────────────┘
```

### Implementation

```go
type Config struct {
    AllowedOrigins   []string
    AllowedMethods   []string
    AllowedHeaders   []string
    ExposedHeaders   []string
    AllowCredentials bool
    MaxAge           int
}
```

---

## Consequences

### Positive

- **Flexible**: Configure as needed
- **Secure defaults**: Empty origin list = no CORS

### Negative

- **Configuration required**: Must set origins
